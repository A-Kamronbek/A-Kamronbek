## Projects

### [Graphix](https://github.com/A-Kamronbek/Graphix)

Online store for a clothing brand in Uzbekistan, live at [graphix.uz](https://graphix.uz). I built it for a client and still maintain it.

- Storefront in Uzbek, Russian and English
- Phone-number accounts verified by SMS
- Click payments confirmed by webhook, with row-locked order creation
- Staff panel so the owner runs products, orders and reviews without a developer
- 950+ automated tests, run on every push by GitHub Actions

### [Graphix-bot](https://github.com/A-Kamronbek/Graphix-bot)

The Telegram notification service behind the store. It receives HMAC-signed webhooks and relays paid orders, contact messages and reviews to the shop's chat. Python standard library only.

### [TapCon](https://github.com/A-Kamronbek/TapCon)

NFC tap-to-pay web app for sellers in Uzbekistan: a customer taps the seller's card and pays with Click, Payme, Uzum or Paynet. Multi-tenant Django with an interface in Uzbek, Russian and English. The website is complete and not yet launched to the public.
